# IoT Device

Sistema IoT para controle e rastreabilidade de acesso a compartimentos
utilizando ESP32-C3, RFID e servomotores.

## Hardware

- ESP32-C3 Super Mini
- RC522 MFRC522
- OLED 128×32 I²C
- 2 servomotores
- 2 switches
