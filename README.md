# iot_device
ESP32-C3 Super Mini — processamento, controle dos periféricos e comunicação Wi-Fi. RC522 MFRC522 — identificação dos cartões/chaveiros RFID. OLED 128×32 I²C — interface visual do sistema. 2 servomotores — acionamento mecânico dos mecanismos. 2 switches — monitoramento/controle físico dos compartimentos.
